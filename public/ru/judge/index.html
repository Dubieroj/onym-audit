Место аудита Onym — проверить за пять минут

Audit.md описывал место аудитора и прямо говорил, что конкретного профиля нет. Эта работа — такой профиль, два независимых проверяющих клиента, набор проверок соответствия и работающий пост, который может занять любой — из браузера, с личностью Onym.

I.

С чего начать

Три пути, по несколько минут каждый. Всё, что вы делаете, подписывается в вашем браузере и проверяется кодом из репозитория.

  1. Откройте приложение, создайте личность аудитора (двенадцать слов — ключ выводится ровно так же, как в приложениях Onym), зарегистрируйтесь и проверьте что-нибудь: например, каталог Discovery https://foldy.io/audit/discovery/manifest.json прогоняется набором из 42 проверок. Подпишите и опубликуйте — библиотека проверит подписи в вашем браузере и покажет якорь в Stellar.
  2. Второй личностью откройте вкладку «Заказчик», закажите аудит у только что созданного аудитора, затем возьмите заказ как аудитор и подпишите: опубликованный заказ несёт три подписи — проверяемого, плательщика и аудитора.
  3. Из репозитория — тесты и весь жизненный цикл аттестации одной командой:
терминал
git clone https://github.com/Dubieroj/onym-audit && cd onym-audit
go test ./...                                   # 110 тестов и подтестов, включая закреплённые фикстуры
node tools/verify-js-test.mjs                   # независимый браузерный клиент, те же векторы
node tools/onym-id-test.mjs && node tools/stellar-test.mjs
tools/sandbox.sh                                # выдача, ответ, заказ, замена, отзыв, подмена байт
go build -o bin/onym-audit ./cmd/onym-audit
bin/onym-audit conformance-discovery -manifest https://foldy.io/audit/discovery/manifest.json

III.

Что проверено — и что нет

Проверено

  • 110 тестов и подтестов на Go; браузерный клиент, вывод ключей и кодирование Stellar — на тех же векторах, что и Go.
  • Ключи личности совпадают с межплатформенной фикстурой приложений Onym; тестовая сеть Stellar приняла транзакции якоря.
  • Каждый сценарий на живом сайте — регистрация, проверка, заказ, заявка, отклик, публикация, отзыв, вход с другого устройства — с удалением тестовых данных после.
  • Каталог Discovery этого сайта проходит набор: CLEAR. Каталог самого Onym не проходит из-за истёкшего снимка — опубликованная и закреплённая в Stellar аттестация показывает, почему именно.

Пока нет

  • Приложения Onym ещё не читают аттестации: экран контракта по-прежнему пишет «Pending — no audits yet»; pull request требует согласия мейнтейнера.
  • Якоря — в тестовой сети Stellar, как и контракты самого Onym сейчас.
  • Пока аттестован только один реальный компонент Onym — его каталог Discovery.
  • Один сервер; воспроизводимой сборки контрактов Onym пока нет, поэтому нет и аттестации их сборки.

Связи

Сделано участником Sobor 2026 — конкурса, который организует мейнтейнер эталонных компонентов Onym. Каждая аттестация о компоненте под управлением Onym указывает эту связь.
