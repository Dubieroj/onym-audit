Аудитор — это отдельная личность Onym: двенадцать слов, из которых ключ аудитора и Stellar-адрес выводятся ровно так же, как в приложениях Onym. Добавьте эти слова в приложение Onym вторым аккаунтом — и увидите тот же адрес.

Кабинет заказчика открывается фразой из двенадцати слов — так же, как в приложениях Onym. Для каждого заказа и заявки из неё выводится свой ключ, поэтому ваши заказы не связаны ни между собой, ни с ключом аудитора.

Никогда не вводите здесь фразу своего основного аккаунта Onym. Эта фраза — вся ваша личность: сообщения, группы и ключи, а ключ аудитора публичен и связал бы вашу работу аудитора с перепиской. Используйте фразу, созданную только для аудита.

Не вводите здесь фразу основного аккаунта Onym — в ней вся ваша личность. Заведите отдельную фразу для заказов.

Фраза не покидает страницу и не сохраняется: браузер хранит только ключи, которые нельзя извлечь. В сеть Stellar ничего не записывается, деньги не нужны.

      Stellar-адрес (G…) одного аудитора; оставьте пустым, чтобы спросить всех. Владелец адреса сможет ответить, зарегистрировавшись аудитором по своей фразе.

      Точные байты закрепляются сразу, поэтому все аудиторы отвечают про одно и то же. Заявка публична (или видна только адресату); контакт (необязательно) спрашивается, только когда вы выбираете предложение, и уходит только этому аудитору.

      Аудиторы

      Сортировка по публичным фактам, которые любой пересчитает по опубликованным заказам аудиторов. Это не оценка качества — ключи бесплатны, поэтому счётчики можно накрутить, — а кому доверять, решаете вы.

      Заказ подписывается ключом, выведенным из вашей фразы только для этого заказа: файл хранить не нужно, и ничто не связывает его с другими вашими заказами или ключом аудитора. Контакт видит только аудитор.
