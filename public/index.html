Check it yourself

From a terminal, with the reference client:

go install ./cmd/onym-audit   # from the source repository
onym-audit verify -manifest MANIFEST_URL \
  -attestation ATTESTATION_URL \
  -target COMPONENT_MANIFEST_URL [-target-document PINNED_DOCUMENT_URL] \
  -credit OPERATOR_KEY

Or compare digests by hand: an attestation applies only while sha256 of the component's manifest (and of the pinned document, if any) equals what it names.

curl -s COMPONENT_MANIFEST_URL | shasum -a 256
