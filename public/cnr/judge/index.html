I.

Počnite ovdje

Tri puta, po nekoliko minuta. Sve što uradite potpisuje se u vašem pregledaču i provjerava kodom iz repozitorijuma.

  1. Otvorite aplikaciju, napravite identitet revizora (dvanaest riječi — ključ se izvodi tačno kao u Onym aplikacijama), registrujte se i pregledajte nešto: npr. Discovery katalog https://foldy.io/audit/discovery/manifest.json prolazi skup od 42 provjere. Potpišite i objavite — biblioteka provjerava potpise u vašem pregledaču i prikazuje Stellar sidro.
  2. Drugim identitetom otvorite karticu „Naručilac“, naručite reviziju od upravo napravljenog revizora, zatim preuzmite narudžbu kao revizor i potpišite: objavljena narudžba nosi tri potpisa — subjekta, platioca i revizora.
  3. Iz repozitorijuma — testovi i cijeli životni ciklus atestacije jednom komandom:
terminal
git clone https://github.com/Dubieroj/onym-audit && cd onym-audit
go test ./...                                   # 110 testova i podtestova, uključujući fiksirane testne primjere
node tools/verify-js-test.mjs                   # nezavisni klijent u pregledaču, isti vektori
node tools/onym-id-test.mjs && node tools/stellar-test.mjs
tools/sandbox.sh                                # izdavanje, odgovor, narudžba, zamjena, opoziv, promjena bajtova
go build -o bin/onym-audit ./cmd/onym-audit
bin/onym-audit conformance-discovery -manifest https://foldy.io/audit/discovery/manifest.json

III.

Šta je provjereno — a šta nije

Provjereno

  • 110 Go testova i podtestova; klijent u pregledaču, izvođenje ključeva i Stellar kodiranje na istim vektorima kao Go.
  • Ključevi identiteta se poklapaju s međuplatformskim testnim primjerom Onym aplikacija; Stellar test mreža je prihvatila transakcije sidra.
  • Svaki tok na živom sajtu — registracija, pregled, narudžba, zahtjev, odgovor, objava, opoziv, prijava s drugog uređaja — uz brisanje test podataka nakon toga.
  • Discovery katalog ovog sajta prolazi skup: CLEAR. Onym sopstveni pada zbog isteklog snimka — objavljena atestacija, učvršćena u Stellar, pokazuje tačno zašto.

Još ne

  • Onym aplikacije još ne čitaju atestacije: ekran ugovora i dalje piše „Pending — no audits yet“; pull request traži saglasnost održavaoca.
  • Sidra su na Stellar test mreži, kao i Onym ugovori danas.
  • Za sada je atestovana samo jedna stvarna Onym komponenta — njen Discovery katalog.
  • Jedan server; ponovljivog build-a Onym ugovora još nema, pa ni atestacije njihovog build-a.

Veze

Napravljeno kao učesnik Sobor 2026, takmičenja koje organizuje održavalac Onym referentnih komponenti. Svaka atestacija o komponenti kojom upravlja Onym navodi ovu vezu.
